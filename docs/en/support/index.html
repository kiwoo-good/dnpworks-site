FAQ

When will Home Tidy be available?

We are preparing the release. We will announce it on this site.

Do I need to switch launchers?

No. It works with the Samsung One UI Home or Pixel Launcher you already use. It does not work when another home app is set as default.

Can I undo a tidy?

Yes. It remembers the layout from before and restores it when you tap Undo.

Does it ever remove apps?

No. It only changes where icons and folders are. It never uninstalls or disables apps.
