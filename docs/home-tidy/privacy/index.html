홈 정리(Home Tidy) 개인정보처리방침

홈 정리는 휴대전화 홈 화면의 아이콘과 폴더를 사용자가 승인한 정리안대로 옮겨 주는 앱입니다. 현재 버전은 인터넷에 연결하지 않으며, 아래 정보는 모두 사용자의 휴대전화 안에서만 처리됩니다.

1. 처리하는 정보

2. 외부 전송 · 제3자 제공 · 위탁

없습니다. 현재 버전에는 인터넷 권한이 없어 위 정보를 기기 밖으로 보낼 수 없습니다. 광고·분석·오류 보고 도구(SDK)가 들어 있지 않으며, 제3자에게 제공하거나 처리를 맡기지 않습니다. 기기 백업과 기기 간 데이터 이전에서도 이 앱의 데이터는 제외됩니다.

3. 접근성 서비스(AccessibilityService API) 사용

  • 읽는 대상: 기본 홈 앱(삼성 One UI 홈, 픽셀 런처)의 홈 화면과 앱스 화면에 보이는 아이콘·폴더·위젯의 이름과 위치.
  • 하는 일: 사용자가 '정리'·'되돌리기'·'넣기'를 누른 경우에만 화면 조작(탭·길게 누르기·끌기·두 손가락 모으기)으로 아이콘을 옮기고, 폴더를 만들거나 풀고 이름을 붙이고, 빈 페이지를 지우거나 추가하고, 앱스 화면의 정렬 방식을 바꿉니다.
  • 진행 중에는 화면 위에 진행 상황과 중지 버튼을 띄우고 다른 터치를 막습니다.
  • 정리·되돌리기가 진행되는 동안에만, 전화가 오거나 휴대전화를 접고 펴면 바로 멈추기 위해 화면에 뜬 창이 어느 앱 것인지와 새 알림이 전화 알림인지를 확인합니다. 알림의 내용은 읽지 않습니다.
  • 앱을 삭제하거나 사용 중지하는 동작은 하지 않습니다.
  • 접근성 서비스로 읽은 정보는 홈 화면 정리에만 쓰며, 광고나 분석에 쓰지 않습니다.
  • 앱 안의 사용 안내에 동의하기 전에는 접근성이 켜져 있어도 아무것도 하지 않습니다. 동의는 앱 첫 화면 아래 '접근성 사용 안내 다시 보기'에서 언제든 철회할 수 있습니다.

5. 이용자의 권리와 삭제 방법

  • 각 권한은 휴대전화 설정에서 언제든 끌 수 있습니다.
  • 설정 > 애플리케이션 > 홈 정리 > 저장공간 > 데이터 삭제, 또는 앱 삭제로 저장된 정보가 모두 지워집니다.
  • 운영자는 이용자의 정보를 가지고 있지 않으므로, 열람·정정·삭제는 위 방법으로 기기에서 직접 하실 수 있습니다.

6. 아동

이 앱은 만 14세 미만 아동을 대상으로 하지 않으며, 아동의 개인정보를 수집하지 않습니다.

7. 방침의 변경

내용이 바뀌면 이 페이지에 시행일과 함께 올리고, 처리하는 정보가 늘어나는 변경은 앱 안에서 다시 동의를 받습니다. 인터넷 연결이나 광고처럼 정보가 기기 밖으로 나갈 수 있는 기능을 넣을 때에도, 그 버전을 내기 전에 이 방침을 고치고 앱 안에서 다시 동의를 받습니다.
