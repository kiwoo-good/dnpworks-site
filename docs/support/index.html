런처를 바꿔야 하나요?

아니요. 지금 쓰는 삼성 One UI 홈이나 픽셀 런처를 그대로 씁니다. 다른 홈 앱을 기본으로 쓰는 경우에는 동작하지 않습니다.

네. 정리 전 배치를 기억해 두었다가 되돌리기를 누르면 그대로 돌려놓습니다.

아니요. 아이콘과 폴더의 위치만 바꾸며, 앱을 삭제하거나 사용 중지하지 않습니다.
