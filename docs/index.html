개발 중

홈 정리가 뭐예요?

런처를 바꾸지 않고, 지금 쓰는 홈 화면의 아이콘만 정리해 주는 안드로이드 앱입니다. 정리안을 먼저 보여 주고, 승인한 뒤에만 움직입니다.

  • 삼성 One UI 홈, 픽셀 런처에서 그대로 사용
  • 마음에 안 들면 한 번에 되돌리기
  • 전화가 오면 정리를 바로 멈춤
홈 정리 자세히 보기
1
읽기지금 홈 화면의 아이콘과 폴더 배치를 읽습니다.
2
미리보기어떻게 정리할지 정리안을 먼저 보여 드립니다.
3
정리승인하면 아이콘을 옮기고 폴더를 만듭니다.
4
되돌리기마음에 안 들면 정리 전 배치로 돌려놓습니다.
